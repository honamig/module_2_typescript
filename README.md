# TypeScript Task Planner

 It is a simple web application for managing tasks and assignments. Users can add tasks with information such as a task name, course, due date, and priority. 

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download/clone this repository
2. Open the project folder in VS Code
3. Install the required dependencies with npm install
4. Compile the TypeScript code with npx tsc
5. Open the HTML file in a web browser

Instructions for using the software:

1. Enter the task information, such as the task name, course, due date, and priority
2. Click the button to add the task
3. View your tasks in the task list
4. Mark a task as completed when you finish it
5. Delete a task when you no longer need it
